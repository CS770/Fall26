Notes

  • The data. ratings.csv and stories.csv are practice set A (GenAI and story writing: one row per rating, one row per story); debates.csv is practice set B (debating GPT-4, one row per participant). Codebooks are on the practice-data page.
  • Edit freely. Change a variable, add a line, run again. Objects you create stay available until you reload the page; Reset code restores the example.
  • Your own data. Load your CSV reads the file into this page as mydata.csv and switches to the Your own CSV example. It never leaves your computer.
  • Packages. psych and GPArotation are loaded. Others from CRAN can be added with webr::install("name"); most are available, and each one adds download time.
  • Same code, real R. Everything here runs unchanged in R or RStudio on your own computer, with the CSVs from the practice-data page in your working folder.
