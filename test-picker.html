One hypothesis at a time

Pick one hypothesis and name its outcome (what you measured) and its predictor (what you manipulated or compared). Run through this once per hypothesis.

    Notes

    • A starting point. The picker matches the test to your variables and design. Your hypothesis still decides which comparison matters, so name it before you look at the data.
    • Unit of analysis first. If each person, story, or item contributes several rows, either average up to that unit or use a mixed-effects model. Treating those rows as independent inflates your sample.
    • Report the size. Every path ends with an effect size and its CI. Write the estimate before the p-value, as on Oct 30.
    • Run it. Each result links to an example in the R lab on practice set A or B. Change the variable names and it runs on your own CSV.
